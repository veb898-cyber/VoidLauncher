# Комнаты друзей в VoidLauncher: технический отчёт по исследованию Tailscale

Статус: **исследование, архитектура реализована**. Реализация завершена и доступна в интерфейсе («Сетевая игра»). Дата: 19.09.2026. Источник: документы Tailscale (июл–сент 2026), Minecraft Wiki,
headscale README, живые тесты на машине владельца.

---

## 1. Целевая UX-модель

`ABCD-1234 → VoidLauncher room → Tailscale access → host peer → Minecraft endpoint`

- Код `ABCD-1234` — **UI-код комнаты VoidLauncher**, не обязательно hostname Tailscale.
- Игровой трафик не проходит через ваш backend (P2P через Tailscale, direct или DERP).
- Minecraft не модифицируется (LAN-мир, join по `IP:порт`).
- Tailscale полностью скрыт внутри VoidLauncher (пользователь не видит IP/порт/VPN).

## 2. Модель пользователей Tailscale

**Подтверждено доками:**
- 1 аккаунт = 1 человек; аккаунт не может применяться несколькими людьми.
- Auth key аутентифицирует устройство как пользователя, создавшего ключ.
- На Personal (free forever): **до 6 пользователей**, до 3 ACL-групп,
  50 tagged resources, устройства без лимита.
- «Playing games with friends» прямо названо допустимым использованием Personal.
- Лимиты (3 группы, 6 юзеров, 50 ресурсов) сейчас не enforced; enforcement начнётся
  «в ближайшие месяцы» (с уведомлениями и эмейл-инвайтами) — следить.

**Решение MVP:** каждый пользователь со своим бесплатным аккаунтом; до 5 друзей
как основной сценарий (влезает в лимит 6 пользователей).

## 3. Изоляция: Machine Sharing (выбранный путь)

**Подтверждено (док «Share your machines», Jan 2026):**
- Sharing доступен на всех планах (beta). Расшарянной машине видна контекстуальная
  часть: получатель видит ТОЛЬКО расшаренную машину, не весь tailnet.
- Создание инвайта — **только из admin console** (Machines → ⋯ → Share).
  Ни CLI, ни API не создают share-инвайты (в API-реестре нет таких endpoints).
- Виды инвайтов: по email (одноразовая ссылка) или invite link
  (одноразовый или reusable до 1000 использований). Неиспользованные живут 30 дней.
- Отзыв — вручную в admin console; после отзыва нужен новый инвайт и повторное принятие.
- Получатель обязан быть Owner/Admin/IT admin **своего** tailnet (свой бесплатный аккаунт).
- По умолчанию **quarantine**: машина отвечает на входящие, но не инициирует исходящие —
  подходит для Minecraft (гость инициирует).
- Grants/ACL: сужение до конкретного порта (`ip: ["25565"]`), `autogroup:shared`,
  email-получатели в правилах — все работает.
- MagicDNS: расшая машина резолвится только как `<hostname>.<tailnet>.ts.net`
  (в лаунчере будем брать IP из `status --json`).

**Критическое ограничение MVP:** создание share-инвайта — ручной шаг владельца в
admin console. Друг один раз принимает приглашение через браузер. После этого —
максимальная автоматизация.

## 4. Установка/управление Tailscale (MSI)

**Подтверждено живым тестом (Windows 11, MSI 1.102.4):**
- Официальный MSI: `https://pkgs.tailscale.com/stable/tailscale-setup-<ver>-amd64.msi`
  (+ `.msi.sha256`, проверена локально).
- Тихая установка: `msiexec /i <msi> /quiet /norestart` + `TS_*`-свойства
  (`TS_ONBOARDING_FLOW=hide`, `TS_UNATTENDEDMODE=always`, `TS_*MENU=hide`) →
  без GUI, политики пишутся в `HKLM\SOFTWARE\Policies\Tailscale`.
- `TS_NOLAUNCH=1` — предотвращает запуск GUI/tray при установке (в реестр не пишется).
- Обнаружение установленного клиента: путь `C:\Program Files\Tailscale\tailscale.exe`,
  служба `Tailscale`, реестр политик.
- Удаление: `msiexec /x <msi или ProductCode> /quiet` — checked, чисто.
  ProductCode 1.102.4: `{AABAAA70-B2CD-5043-9922-0B190DC6D677}` (per-версия; лаунчеру
  кэшировать скачанный MSI).
- CLI: `tailscale status --json`, `set --hostname`, `up --auth-key`, `ip -4`,
  `logout`, `login` — всё поддается программному вызову.
- Фаервол: установка создаёт правила `Tailscale-In` (Allow, `Program=Any`,
  `LocalAddr=100.x.y.z`, профили Domain/Private) → входящие к ЛЮБОМУ процессу
  (в т.ч. Java/Minecraft) на Tailscale-интерфейсе разрешены.

**Лицензия (ToS, Aug 2026):**
- Limited, revocable, non-transferable license на скачивание/использование клиента
  в рамках Tailscale Solution. Скачивание с официального pkgs.tailscale.com легально;
  передистрибуция бинарника как своего запрещена.
- Скрытое управление из стороннего лаунчера — это официальный MDM-механизм
  («Deploy with MDM available on all plans»): MSI-свойства `TS_*` + CLI. ToS не блокирует.
- Секретов в команду установки не передавать (токены/ключи — отдельно и только при входе).

## 5. Minecraft

**Подтверждено (Minecraft Wiki):**
- LAN-мир: пауза → «Открыть для LAN» или `/publish [gamemode] [allowCommands] [port]`.
- Порт по умолчанию случайный в 25565–25575, редактируется с 1.19.3; в журнале/чате
  «Local game hosted on port N» (парсить).
- На чужой сети мир не появляется в списке LAN — только явный адрес `IP:порт`.
- VPN — задокументированный способ «симуляции LAN», join по Tailscale IP работает
  по тому же принципу.
- LAN-миры не требуют онлайн-аутентификации (возможен вход альтернативными никами).
- Автозапуск: `--quickPlayMultiplayer "host:port"` (1.20.2+) или legacy
  `--server <ip> --port <port>`.

**Статус:** cross-network вход **не проверен** — отложенный эксперимент до второго
участника. Локально подтверждён только путь фаервол+интерфейс.

## 6. Direct vs DERP

`netcheck` на сети владельца (18.09.2026): UDP=true, MappingVariesByDestIP=false,
PortMapping=пусто (UPnP нет), IPv6 нет; ближайший DERP Helsinki ~182 мс.
**Локальный netcheck — только индикатор, не доказательство.** Точная классификация
direct/relay — при втором участнике (`ping --until-direct`, `status --json Peer.CurAddr`).

## 7. Альтернативы (не включаются в MVP)

- **Одна tailnet + tailnet-user invites**: лимит 6 пользователей, ACL-groups до 3,
  создание инвайтов тоже только admin console. Возможен как эволюционный шаг.
- **headscale** (self-hosted control server): свои пользователи/инвайты/ACL без лимитов,
  полная автоматизация; но это инфраструктура и зона ответственности. Expansion-вариант.
- **Auth keys / общий аккаунт**: некорректно по модели Tailscale («аккаунт = человек»),
  auth key для ПК друзей не используется.

## 8. Решения для MVP (как понял владелец)

- Tailscale Cloud (не headscale), каждый со своим бесплатным аккаунтом.
- Machine Sharing как способ изоляции; до 5 друзей.
- `ABCD-1234` = UI-код комнаты VoidLauncher (не обязательно hostname).
- Backend/headscale пока не добавляем. Игровой трафик через наш backend не идёт.
- Известное ограничение: создание share-инвайта — ручной шаг (admin console),
  принятие друга — одноразовый браузерный шаг. Дальше — автоматизация.
